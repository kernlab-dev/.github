模块分两层：
- `.github/workflows/reusable-*.yml` 是 `workflow_call` 型组织级实现，按字母阶段编号分层：e10-policy（来源/Tag/版本强校验）、v10-ci（构建+测试矩阵）、v30-docs（PR 内 md/mdx 站内死链接检查）、m10-docs-merge（docs-only PR squash+删分支）、w10-docs-deploy（站点聚合上站）、r10-release（双模 NuGet 发布）、o10-nuget-unlist（预发布包软下架运维工具，要求 NUGET_UNLIST_USER）。此外保留旧版 reusable-release、reusable-e20-triage、reusable-docs-* 供遗留仓过渡。
- `workflow-templates/gate.yml` + `gate.properties.json` 是唯一的仓库入口桩：按 `e10→e20→(v10|v30→m10)→(r10/w10)` 编排 needs 图，并显式注入 `id-token: write` 以满足 r10-release OIDC Trusted Publishing 顶层权限需求。

依赖方向单向向内：每个仓库仅保留一个 `<repo>/workflows/gate.yml` 调用本仓库 reusable；reusable 之间不互相调用，仅通过 `needs.<job>.result` / triage.outputs 共享状态（如 `docs_only`）。r10-release 支持 API key 与 OIDC 双发布模式（缺 `NUGET_API_KEY` 时回退 `NuGet/login` OIDC），且对缺失 snupkg 做存在性容错；o10-nuget-unlist 强制 `confirm=unlist` 且拒绝非 prerelease 版本号。
