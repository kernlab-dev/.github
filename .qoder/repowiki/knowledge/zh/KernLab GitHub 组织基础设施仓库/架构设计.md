本仓库以「公共可见层 + .github-private 成员可见细节」二分暴露组织治理：
- 根级 `README.md`/`SECURITY.md`/`SUPPORT.md`/`VERSIONING.md` 作为 GitHub 组织回退，被未自建同名文件的子仓自动继承。
- `docfx-template/` 提供统一文档站骨架，供各产品仓直接复用样式与构建配置。
- `.github/workflows/` 集中编排可复用流水线：新增 `o10-nuget-unlist.yml`（对 `KernLab.*` 包执行仅 prerelease 软下架，依赖密钥 `NUGET_UNLIST_USER`）；`reusable-r10-release.yml` 实现双模发布（API key 优先、OIDC 兜底，snupkg 失败容错并使用 `id-token: write`）；`reusable-v30-docs.yml` 加入站内死链接检查；同时新增 `reusable-e10-policy`、`reusable-v10-ci`、`reusable-m10-docs-merge`、`reusable-w10-docs-deploy` 等细分步骤工作流。
- 旧的独立 `ci/docs-deploy/policy.yml` + `properties.json` 组合已退役，改为由单一入口 `gate.yml` 按序继承所有 reusable 工作流装配校验链；新仓不再复制 workflow 正文，而是从成员可见的 `workflow-templates/` 取 `ci` / `docs-deploy` 桩并以 `uses:` 引用逻辑。
- `CI-GATE.md` 与 `RULES.md` 在根目录显式声明 Gate 装配策略与诊断 ID 注册表，替代过去散落在子仓的隐性约定。
