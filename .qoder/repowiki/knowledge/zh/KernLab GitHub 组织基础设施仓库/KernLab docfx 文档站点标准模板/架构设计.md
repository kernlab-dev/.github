本模块是纯静态文档站生成骨架，不包含可执行代码，由四份可直接复制到产品 `docs-site/` 目录的文件构成：
- `docfx.json` 为单一入口配置，同时声明 metadata（从 `src/<项目>.dll` 提取 XML 注释生成 api 参考）、build.content（README、各层 toc.yml + docs 目录、COORDINATION 短名映射、perf 子目录、API yml）和 build.resource（注入 `public/main.css`），最终输出 `_site`，依赖 DocFx `default` + `modern` 双模板。
- `toc.yml` 提供顶级导航骨架（首页、章节、API 参考、GitHub）。
- `index.md` 是着陆页骨架，使用 Bootstrap 5 语义类（landing-hero、特性卡、文档导航、快速链接）与 bootstrap-icons。
- `main.css` 是家族统一样式，覆盖 navbar 宽度、TOC sidebar 280px、卡片边框柔和色阶与 Dark 模式配色，作为资源被 `docfx.json` 注入到 `public/main.css`。
依赖方向单向：模板被产品仓复制后通过 docfx CLI 独立构建，不参与源码编译；CI 侧复用上游 `workflow-templates/docs-deploy.yml` 触发聚合发布到 docs.kernlab.dev。
